# Process Documents
A directory that contains all the drafts, planning and miscellaneous thoughts regarding the Mobile Air Quality Sensor.
## Preliminary Documentation
1. preliminary_interview_questions.txt
2. idenfied_problems.txt

The first document attempts to find a general issue that exists. The second document narrows the general issue into a specific problem to tackle. The problem was identified as increasing the spatial resolution of air quality measurements without sacrificing cost and practicality.
## Decisions

2. Decision.docx

These two documents analyze different proposed solutions to the problem of increasing the spatial resolution of air quality measurements without sacrificing cost and practicality. The analysis paragraph document finalizes these thoughts into a write-up.
